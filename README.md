# Emotion Detection Application

This is the final project for the AI Application Development / IBM course.
The application uses IBM Watson NLP library to detect emotions (anger, disgust,
fear, joy, and sadness) from a given text input, and returns the dominant emotion.

## Features
- Emotion detection using Watson NLP EmotionPredict model
- Flask-based web deployment
- Error handling for blank input
- Unit tested with Python's unittest framework
- Passed static code analysis with PyLint (10/10)

## How to run
```bash
python3 server.py
```
Then open the app in your browser.

## Technologies
- Python
- Flask
- IBM Watson NLP
